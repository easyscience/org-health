How these numbers are measured
Schedule
A GitHub Actions workflow rebuilds this page every six hours and on demand.
Code
radon (SLOC, cyclomatic complexity, maintainability index) and interrogate (docstring coverage, with each repository's own settings), the same tools as each repository's dashboard.yml.
Tests
Count of test functions under tests/. Test coverage comes from Codecov where a repository reports to it.
Issues and PRs
GitHub REST API. Open issues exclude pull requests. Awaiting review means a non-draft PR with a requested reviewer.
CI
Latest completed or running non-PR workflow run per workflow and branch.
Unreleased
Lines changed in source and tests between master and develop.
Repositories
Listed in repos.yml in this repository.
